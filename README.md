# sacks
Brings Klei Wright's [Matcha Flavoured](https://modrinth.com/project/QI0EmgZ1)'s Sacks as a separate, individual mod.

Shulker Boxes, now renamed to Sacks, can be crafted with 8 leather and a chest. The goal of this mod is to make the annoying inventory management less tedious in the early-game.
